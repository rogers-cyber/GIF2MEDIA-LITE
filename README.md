# GIF2MEDIA LITE – Lightweight Offline GIF to MP4/APNG Converter v1.0.0

GIF2MEDIA LITE v1.0.0 is a lightweight desktop application designed for fast and reliable GIF-to-video conversion. It allows users to convert animated GIF files into MP4 videos or APNG animations entirely offline.

Built with Python, Tkinter, FFmpeg, ttkbootstrap, and optional drag-and-drop support, GIF2MEDIA LITE focuses on simplicity, speed, and stable batch media processing. It is ideal for creators, designers, developers, content editors, and anyone who needs quick GIF conversion workflows.

------------------------------------------------------------
USAGE GUIDE
------------------------------------------------------------

1. Select GIF Files  
Click "Browse and Select GIF Files" or drag-and-drop GIF files into the application.

2. Choose Output Format  
Select either MP4 or APNG export mode.

3. Configure Export Settings  
Adjust FPS, width resolution, and filename prefix.

4. Select Output Folder  
Choose where converted files will be saved.

5. Start Conversion  
Click "Start Conversion" to begin processing.

6. Monitor Progress  
View live logs, progress updates, and conversion status in real time.

------------------------------------------------------------
CONVERSION WORKFLOW
------------------------------------------------------------

1. User selects GIF files
2. Application validates FFmpeg availability
3. GIF files are loaded for processing
4. Export settings are applied
5. FFmpeg conversion engine starts
6. Progress bar updates in real time
7. Converted media files are generated
8. Exported files are saved successfully
9. Output folder opens automatically (optional)
